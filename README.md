# اختبار الوحدة 11 — الأمن السيبراني وإدارة الحوادث

افتح `index.html` في المتصفح. الاختبار من 60 سؤالاً موقفياً، والعربية هي اللغة الأصلية مع زر للتبديل إلى الإنجليزية.

## سجل النتائج

العلامات تُكتب في [جدول النتائج](https://docs.google.com/spreadsheets/d/1kwgeNZT5XDmEkv6jj_eTTEjvBQd9haT95FiZaH7mq7E/edit).

1. افتح الجدول ثم Extensions ثم Apps Script.
2. الصق محتوى `Code.gs` واحفظه.
3. Deploy ثم New deployment ثم Web app. نفّذه باسمك، واسمح بالوصول Anyone.
4. انسخ رابط `/exec` وضعه في `SHEET_URL` داخل `index.html`.
